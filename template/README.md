# HWPX 기준양식

하이브리드판의 공식 출력 기준은 사용자가 제공한 **여비정산서(양식).hwpx** 입니다.

배포판에서는 다음 경로에 실제 원본 양식을 둡니다.

```text
template/여비정산서(양식).hwpx
```

원본 템플릿은 절대 덮어쓰지 않습니다. 생성 문서는 `output/`에 새 파일로 저장합니다.

GitHub 공개 저장소에는 현재 원본 HWPX 바이너리를 포함하지 않았습니다. 로컬 개발/배포 패키지에서만 기준양식을 배치합니다.
