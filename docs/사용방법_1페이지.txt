개인출장·여비정산 Hybrid v2.0-beta2.1 사용방법

1. start_windows.bat 실행
2. [개인 설정]에서 소속, 근무지, 직위(직급), 성명, km 단가, 서명을 등록
3. [1. 출장 등록]에서 출장목록 Excel(.xlsx/.xlsm/.csv)을 선택하고 미리보기 후 저장
4. [2. 정산 작성]에서 출장 선택 → 이동구분 → 왕복/편도 → 경비/정산일자 입력 → 정산 저장
5. [3. 증빙 등록]에서 영수증 이미지/PDF 등록
6. [2. 정산 작성]에서 HWPX 정산서 생성 또는 A4 화면 인쇄
7. [백업·복원]에서 ZIP 백업을 정기적으로 보관

주의
- 원본 HWPX 양식은 template 폴더에서 보존합니다.
- 생성 문서는 output 폴더에 새 파일로 만듭니다.
- 같은 출장 Excel을 재업로드할 때 기존 정산값은 보존하고 출장 원본정보만 갱신하는 것을 원칙으로 합니다.
- HWPX 서명 이미지는 별도 회귀검증 후 직접 삽입합니다.
- GitHub Pages의 main 웹판과 Windows 하이브리드판은 별도 배포합니다.
